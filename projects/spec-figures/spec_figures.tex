% \Figure{type}{title}: the figure, its TikZ source and its Mermaid / Markdown twin
\newcommand{\Figure}[2]{%
  \clearpage
  \section{#2}
  \begin{center}
    \begin{adjustbox}{max width=\linewidth}\input{tikz/#1}\end{adjustbox}
  \end{center}
  \subsection*{TikZ: \texttt{tikz/#1.tex}}
  \VerbatimInput[fontsize=\footnotesize]{tikz/#1.tex}
  \IfFileExists{mermaid/#1.mmd}{%
    \subsection*{Mermaid twin: \texttt{mermaid/#1.mmd}}
    \VerbatimInput[fontsize=\footnotesize]{mermaid/#1.mmd}}{}%
  \IfFileExists{mermaid/#1.md}{%
    \subsection*{Markdown twin: \texttt{mermaid/#1.md}}
    \VerbatimInput[fontsize=\footnotesize]{mermaid/#1.md}}{}%
}

Every figure is an environment of the \texttt{specfig} package with plain data commands; the layout, the drawing and the consistency checks are generated. Each type also has an independent Mermaid template for Markdown pages. The command reference is in \texttt{README.md} and in the guides in \texttt{llm/}.
